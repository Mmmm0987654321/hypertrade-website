# HyperTrade Website\n\n**Arbitrum Mainnet Trading Platform**\n\n✅ Wallet Connection (Privy)  \n✅ Deposit/Withdraw USDC  \n✅ Spot & Perpetual Trading  \n✅ Real-time Positions  \n✅ Beautiful Dark UI  \n✅ Responsive Design  \n\n## Tech Stack\n\n- **Frontend:** Next.js 15 + React + TypeScript\n- **Styling:** TailwindCSS\n- **Wallet:** Privy + Web3Modal  \n- **API:** Hyperliquid REST API\n- **Database:** Supabase\n- **Chain:** Arbitrum One (Mainnet)\n\n## Quick Start\n\n### 1. Clone & Install\n\n```bash\ngit clone https://github.com/Mmmm0987654321/hypertrade-website.git\ncd hypertrade-website\nnpm install\n```\n\n### 2. Setup Environment\n\n```bash\ncp .env.example .env.local\n```\n\nFill in your credentials:\n- `NEXT_PUBLIC_PRIVY_APP_ID` - From Privy dashboard\n- `NEXT_PUBLIC_SUPABASE_URL` - From Supabase\n- `NEXT_PUBLIC_SUPABASE_ANON_KEY` - From Supabase\n- `NEXT_PUBLIC_ARBITRUM_RPC_URL` - From Alchemy/Infura\n- `NEXT_PUBLIC_BACKEND_URL` - Your FastAPI backend\n\n### 3. Run Dev Server\n\n```bash\nnpm run dev\n```\n\nOpen [http://localhost:3000](http://localhost:3000)\n\n## Pages\n\n- **Dashboard** (`/`) - Portfolio overview, PnL, margin\n- **Trade** (`/trade`) - Place buy/sell orders (spot & perps)\n- **Positions** (`/positions`) - View all open positions\n- **Wallet** (`/wallet`) - Deposit/Withdraw USDC\n\n## Building for Production\n\n```bash\nnpm run build\nnpm start\n```\n\n## Deployment\n\n### Vercel (Recommended)\n\n```bash\nnpm install -g vercel\nvercel\n```\n\n### Docker\n\n```bash\ndocker build -t hypertrade .\ndocker run -p 3000:3000 hypertrade\n```\n\n## Required Backend Endpoints\n\nYour FastAPI backend should provide:\n\n- `POST /api/deposit` - Initiate USDC deposit\n- `POST /api/withdraw` - Initiate withdrawal  \n- `POST /api/order` - Place trade order\n- `GET /api/positions` - Get open positions\n- `GET /api/orders` - Order history\n\n## Features\n\n✨ **Real-time Updates**\n- Live Hyperliquid API integration\n- Position updates every 5 seconds\n\n🔐 **Secure Wallet**\n- Privy embedded wallets\n- MetaMask integration\n- Non-custodial trading\n\n📊 **Trading**\n- Spot trading (BTC, ETH, etc.)\n- Perpetual trading with leverage\n- Limit and market orders\n- Position management\n\n💰 **Deposits & Withdrawals**\n- USDC on Arbitrum\n- Bridge2 gasless deposits\n- Fast withdrawals\n\n## License\n\nMIT\n
